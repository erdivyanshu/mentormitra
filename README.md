# Mentor Mitra Website

Minimal marketing website for Mentor Mitra — built with React, TypeScript, and Vite.

## Pages

- **Home** — Hero, how it works, categories, featured mentors, testimonials
- **Mentors** — Browse mock mentor profiles (click redirects to Google Play)
- **About** — Mission and value proposition
- **Become a Mentor** — Mentor onboarding info
- **Contact** — Contact form with email, topic, and message (mock submit)

## Setup

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Tech stack

- React 19 + TypeScript
- Vite
- react-router-dom
- lucide-react
- In-file CSS (style objects at bottom of each component)

## Play Store link
